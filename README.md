# فرفشة — تطبيق غرف صوتية مباشرة (ويب/PWA)

تطبيق ويب متجاوب يعمل على الحاسوب والجوال: غرف صوتية مباشرة، أدوار، طلب تحدّث،
شات نصي، رقابة كاملة بسجل تدقيق، ولوحة إدارة.

## التشغيل محليًا
```
python -m http.server 8099 --directory .
```
ثم افتح http://127.0.0.1:8099

## النشر
GitHub Pages من الفرع main والجذر /.

## الملفات
- `index.html` شاشة التطبيق
- `assets/app.js` المنطق الكامل
- `assets/app.css` التصميم (فضاء نيون تفاعلي)
- `assets/config.js` إعدادات العميل العامة (مفاتيح عامة — بلا أسرار)
- `sw.js` + `manifest.webmanifest` ليعمل كتطبيق قابل للتثبيت
- `docs/` مصفوفة الميزات المجانية · التكاليف · دليل التسليم
